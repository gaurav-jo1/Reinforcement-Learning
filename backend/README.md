# Backend folders

- `scraped_data/` stores the original Kite HAR captures and extracted response JSON.
- `scrape_data_transform/` contains scripts for extracting responses from HAR files and cleaning candle data into Parquet and CSV files.
- `master_data/` stores the cleaned candle datasets and generated indicator datasets used by the API.
- `venv/` contains the local Python environment and installed backend dependencies.
- `__pycache__/` contains Python's automatically generated bytecode cache.

The backend's `main.py` serves candle data through FastAPI. `indicators.py` calculates indicator datasets and serves the indicator catalog, values, and CSV export.

The frontend lives in the sibling `../frontend/` folder.
