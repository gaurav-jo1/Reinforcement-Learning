# Frontend folders

- `src/` contains the React application, candle chart, indicator checkbox dropdown, API request helpers, indicator loading logic, and styles.
- `public/` contains static assets, including the favicon and SVG icons.
- `node_modules/` contains dependencies installed by npm.
- `dist/` contains the production website generated by `npm run build` with the default output directory.

The frontend uses React and Vite to display candles and indicators from the API in the sibling `../backend/` folder.
